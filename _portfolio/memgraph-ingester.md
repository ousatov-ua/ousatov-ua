Memgraph Ingester indexes source files into Memgraph so AI agents can query a
real code graph instead of repeatedly scanning raw files.

Retrieval is grounded in code structure: files, symbols, relationships,
semantic chunks, and durable project knowledge are connected into graph-backed
context for MCP and RAG workflows.
