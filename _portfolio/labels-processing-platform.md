Led architecture and delivery for an event-driven product label platform across
20+ global markets.

The platform processes 10-50M Kafka events/day with peaks above 5K events/sec,
covering WWMT content, multilingual translation workflows, vendor print
integrations, replayability, schema evolution, and sub-second p95 latency.

Core stack: Java, Spring Boot, Apache Kafka, AWS, Kubernetes, PostgreSQL, and
Docker.
