# Oleksii Usatov

Lead Backend Engineer building reliable distributed platforms, event-driven
microservices, and AI-assisted developer tooling.

## What I Build

- High-throughput backend platforms with Java, Spring Boot, Kafka, PostgreSQL,
  Kubernetes, and AWS.
- Event-driven systems with replayability, schema evolution, observability,
  backpressure, retries, and dead-letter handling.
- AI-agent and code-intelligence tools that help large codebases become easier
  to search, understand, and evolve.
- Developer infrastructure that favors clear contracts, clean boundaries,
  automated checks, and production-ready operations.

## Selected Impact

- 15+ years in software engineering.
- Lead Backend Engineer / Platform Engineer at EPAM Systems.
- Production platforms processing 10-50M Kafka events per day, with peaks above
  5K events per second.
- 20+ production microservices across business-critical domains.
- Backend latency improvements from above 1000 ms p95 to below 200 ms p95.
